# Alphan — Premium React Portfolio

Production-ready Vite + React portfolio for Alphan — Software Engineer & Full-Stack Developer.

## Stack
React, Vite, Tailwind CSS, Bootstrap 5, jQuery, Framer Motion, Lucide React.

## Run
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## Customize
Edit `src/config/profile.js` for identity, links and GitHub username. Project/skill data lives in `src/data/`.

## Notes
The GitHub section uses a polished local activity visualization by default. Replace it with a GitHub API integration later if desired. The contact form is frontend-only and structured for EmailJS/Formspree/backend integration.
